# Proyecto con LocalStorage

## Descripción del proyecto
Simulación de envio de tweets donde guardo los tweets en localStorage permitiendo así que se mantengan al cerrar o recargar el sitio.

## Tecnologías

### HTML5
Utilizado para estructurar el sitio web.

### CSS3
Utilizado para diseñar la interfaz, aplicar estilos y adaptar el sitio web a diferentes dispositivos.

### JavaScript
Utilizado para validar el campo y guardar en localStorage los tweets.
