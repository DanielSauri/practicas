# Buscador de autos

## Descripción del proyecto
Simulación de un buscador de autos por filtros como marca, modelo, año y puertas.

## Tecnologías

### JavaScript
Utilizado para validar los campos, filtrar y mostrar los resultados obtenidos de acuerdo a las especificaciones.
