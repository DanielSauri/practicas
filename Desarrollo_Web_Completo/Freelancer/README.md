# Freelancer

## Descripción del proyecto
Simulación de un sitio web de servicios freelance que incluye un formulario de contacto con validación de campos.

## Tecnologías

### HTML5
Utilizado para estructurar el sitio web.

### CSS3
Utilizado para diseñar la interfaz, aplicar estilos y adaptar el sitio web a diferentes dispositivos.

### JavaScript
Utilizado para validar los campos del formulario.
