# FrontEndStore

## Descripción del proyecto
Simulación de una tienda en línea que ofrece productos relacionados con diferentes tecnologías e incluye una página de información sobre la tienda.

## Tecnologías

### HTML5
Utilizado para estructurar el sitio web.

### CSS3
Utilizado para diseñar la interfaz, aplicar estilos y adaptar el sitio web a diferentes dispositivos.
