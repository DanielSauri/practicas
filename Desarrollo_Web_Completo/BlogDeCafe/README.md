# Blog De Cafe

## Descripcion del proyecto

Blog de cafe es tu lugar seguro donde podras consultar informacion util sobre el mundo del cafe, asi como cursos y talleres. Conocer mas sobre el proyecto y descubrir diferentes contenidos relacionados.

El sitio cuenta con las siguientes secciones:
- Inicio
- Nosotros
- Cursos
- Contacto

## Tecnologias

### HTML5
Se utiliza para estructurar el sitio web.

### CSS3
Se utiliza para diseñar la interfaz, dar estilos y adaptar el sitio web a diferentes dispositivos.

## Objetivos

- Aprender a crear sitios web completos
- Practicar estructura semantica
- Crear sitios web aptos para cualquier dispositivo
- Practicar la organizacion del codigo
